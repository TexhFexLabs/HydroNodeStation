\chapter{Stundenaufwand}
Der zeitliche Aufwand wird nach Projektphasen dokumentiert, zum Beispiel Planung, Entwicklung, Tests und Nachbereitung. Dadurch lässt sich die Verteilung der Arbeitszeit klar bewerten.

Für die finale Version kann hier eine Tabelle mit Kalenderwochen, Aufgaben und Stunden ergänzt werden. Diese Übersicht unterstützt eine realistische Einschätzung des Gesamtaufwands.
