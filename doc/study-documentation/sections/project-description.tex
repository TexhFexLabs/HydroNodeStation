\chapter{Projektbeschreibung}
Das Projekt \textit{HydroNodeStation01} entwickelt eine energieeffiziente Wetterstation für den autarken Außeneinsatz. Ziel ist die zuverlässige Erfassung und Übertragung von Umweltdaten über LoRaWAN.

Der Fokus liegt auf einem robusten Gesamtsystem aus Elektronik, Firmware und Gehäuse. Die Ergebnisse sollen als Grundlage für einen skalierbaren Einsatz mehrerer Stationen dienen.
