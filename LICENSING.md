## Why these licences

**CERN-OHL-S v2 for the hardware.** It is the reference licence for open-source
hardware and it is *strongly reciprocal*: anyone may study, build, modify, and
sell this board, but if they distribute a modified design they must release
their changes under the same terms. The community keeps the derivatives.

**CC BY-SA 4.0 for the documentation.** Same reciprocal idea, applied to text
and images. Creative Commons explicitly recommends against using CC licences
for hardware designs or software, which is why they are scoped to documentation
only here.

**MIT for the firmware.** No friction. Anyone can lift a sensor driver from this
repository into a completely unrelated project without licence contamination.
Sensor drivers are exactly the kind of code that should be trivially reusable.

## Reusing this project

**You may**, under the terms above:

- build the board, for yourself or commercially
- modify the schematic, PCB, and enclosure
- sell assembled stations
- lift the firmware drivers into your own projects
- reuse the documentation

**You must**, in return:

- credit the original project (all three licences require attribution)
- release modified *hardware designs* under CERN-OHL-S v2 (hardware reciprocity)
- release modified *documentation* under CC BY-SA 4.0

The MIT-licensed firmware carries no reciprocity requirement.

## Notice for redistribution

If you build and distribute hardware based on this design, CERN-OHL-S v2 §3.3
requires you to pass on the design files (or a written offer for them) together
with the product, and to keep the licence notices intact.
